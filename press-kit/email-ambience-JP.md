**件名:** 無料・オープンソースのアルゴリズミック・リバーブ（16ch FDN）— OTODESK の Ambience

---

BPB チームの皆さん、こんにちは。

私は OTODESK という名義で、無料・オープンソースの VST3 プラグインを一人で開発している、独学の開発者です。最新作をぜひ紹介させていただきたく、BPB の無料プラグイン記事にぴったりだと思いご連絡しました。

**Ambience** は、16 チャンネルの Feedback Delay Network を核にした、リサーチグレードのアルゴリズミック・リバーブです。

- 7 種のリバーブアルゴリズム（ROOM / HALL / PLATE / SPRING / GOLDFOIL）
- 実在する世界の名空間をモデル化した 21 のファクトリープリセット（Abbey Road、Vienna Musikverein、Concertgebouw、Carnegie Hall、EMT 140 ほか）
- 周波数依存 RT60 を実現する Välimäki–Liski の 10 バンド GEQ 吸収ステージ
- ISM ベースの Early Reflections、ADAA サチュレーター（Warm / Tape / Tube / Hard）、リアルタイム D50 / C50 / C80 / EDT 計測表示

そして、**完全無料・オープンソース（GPLv3）** です。

なぜ作ったか：私は音響工学の専門家ではなく、ただの趣味のプロデューサーです。商用リバーブの多くが今も 1960 年代の土台（Schroeder、Moorer、Jot）に乗っていて、プリセットと UI で売られていることに不満を感じ、論文から DSP の土台そのものを、AI を壁打ち相手に、無数のビルドエラーを乗り越えながら再構築しました。その結果が Ambience です。この一年で、同じやり方で 12 個のプラグインをリリースしました。すべて無料・オープンソースです。
