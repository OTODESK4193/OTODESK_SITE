# OTODESK — Press Kit / BPB Submission Package

This folder contains everything you need to pitch **Ambience** (and OTODESK in general) to Bedroom Producers Blog and similar outlets.

## Contents
- `email-ambience-EN.md` — Ready-to-send pitch email (English). **Start here.**
- `email-ambience-JP.md` — Japanese reference translation (for your own check; do NOT send this).
- `fact-sheet-EN.md` — One-page fact sheet / spec sheet for Ambience. Attach or paste if asked for details.
- `outlet-list.md` — Where to send it, contact addresses, and submission tips.
- `followup-EN.md` — Polite 1-time follow-up template if you get no reply.
- `screenshots/` — High-res images (1920px wide):
  - `ambience-hero.png` — The hero shot. Use as the lead image.
  - `ambience-engine.png` — "Inside the box" technical section.
  - `site-index.png` — The full OTODESK catalog (shows you've shipped 12 plugins).

## How to use (quick version)
1. Open `outlet-list.md`, find the current BPB submission address (verify on their site first).
2. Copy the body of `email-ambience-EN.md` into your mail client.
3. Attach 2–3 screenshots from `screenshots/` (or paste the GitHub/site links — they have everything).
4. Send. Wait 1–2 weeks.
5. If no reply, send `followup-EN.md` **once**.

## Golden rules
- **One plugin per pitch.** Lead with Ambience only. Don't dump all 12.
- **Lead with the story** (hobbyist rebuilt reverb DSP from papers), not the spec list.
- **Stay humble.** "Happy to provide whatever you need" beats "please feature me."
- **The moment you're featured:** post it everywhere, and have your X/note/newsletter ready to catch the traffic.
