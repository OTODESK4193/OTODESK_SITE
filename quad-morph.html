Quad Morph Filter

28モデル・リアルタイムモーフィング ＋ 200プリセット。あらゆる空間周波数を支配する。

Quad Morph Filter は、28 種類のハンドクラフトされたフィルターアルゴリズムを XY パッド上でリアルタイムにモーフィング可能なオープンソース VST3 プラグイン。v1.1.0 では使いやすさと音質が飛躍的に向上！FILTER / MOD / OUT のタブ構成UIへの刷新、200 種類の即戦力ファクトリープリセット、10 カラーテーマ切り替え、周波数応答表示の拡大（対数圧縮dB軸）を導入しました。

VERSION 1.1.0 MAJOR UPDATE (2026/8/9)
■ v1.1.0 主な更新・追加機能
  • 200 ファクトリープリセット標準搭載: Classic Analog、Acid & Squelch、Vocal & Formant、Rhythmic、Ambient、Lo-Fi、Bass 等 10 カテゴリ全 200 プリセットをブラウザ付きで実装。
  • 使いやすさと音質の向上（GUI / DSP 刷新）: FILTER / MOD / CONFIG のタブ切替構成を導入。コントロール空間を確保し、表示の視認性と操作性を劇的改善。
  • 高精細・大画面 周波数応答アナライザー: インラインバー・スライダー化とともに応答グラフ描画領域を拡大。0dB以上を対数圧縮（Square-root）し、+70dBの強烈なレゾナンスピーク時も波形が潰れず可視化。
  • 10 カラーテーマ切り替え: Midnight / Sakura / Ocean / Forest / Sunset / Mono / Neon / Vaporwave / Amber / Arctic の 10 テーマをワンクリック切替。
  • DSP 正確性 ＆ ホスト互換性・リアルタイム安全の追求: 音声スレッド内でのヒープアロケーション完全ゼロ化（10,000回/秒のmalloc排除）、AVX2並列加速、4倍オーバーサンプリング (2×/4×)、自動ゲイン補正 (AGC)。
// Visual Showcase

v1.1.0 全4画面インターフェース

01 / FILTER TAB — 4-FILTER MATRIX & LIVE CURVE
FILTER タブ — 4フィルター・マトリクス ＆ リアルタイム周波数応答
A/B/C/D 4つのフィルターを選択し、XYパッドでイコールパワー・モーフィング。各フィルターの個別カーブと、合成された発光レスポンスラインをリアルタイム描画。インラインバー・スライダーと Solo ボタンにより、直感的なサウンドメイキングが可能。
02 / MOD TAB — 5-LFO SYSTEMS & ENVELOPE FOLLOWER
MOD タブ — 5系統 LFO ＋ LFO4 (Rate Mod) ＋ LFO5 (Dry/Wet) ＋ EnvFollower
XYモーフィング用 LFO1、Cutoff用 LFO2、Resonance用 LFO3 に加え、LFO自体の周期を変調する LFO4 (Rate Mod)、Mix量を揺らす LFO5 (Dry/Wet Mod) を搭載。入力信号に追従するサイドチェーン式 Envelope Follower も完全統合。
03 / PRESET BROWSER — 200 FACTORY PRESETS & SEARCH
PRESET ブラウザ — 10カテゴリ 200 ファクトリープリセット ＆ 検索機能
ヘッダーの PRESET ボタンから瞬時に展開。All / Factory / User / Favorites の4ビュー、カテゴリフィルター、キーワード検索、ワンクリックお気に入り登録を完備。ランダム選択機能で瞬時にインスピレーションを発掘。
04 / CONFIG TAB — 10 COLOR THEMES & OVERSAMPLING
CONFIG タブ — 10 カラーテーマ ＆ 4倍オーバーサンプリング ＆ AGC
Midnight / Sakura / Ocean / Neon など 10 種類のカラーテーマを選択可能。 Moog や TB-303 のエイリアシングを抑える Off / Auto / 2× / 4× オーバーサンプリング設定および入力エンベロープ深度を統括。
