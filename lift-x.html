LIFT-X

31個のエンベロープが連動する驚愕のライザープラグイン

ライザーは単なる音量エンベロープではない——31個のカーブが同時に躍動する音楽的展開である。3×OSC、1×NOISE、4×Filter、5×FXの全パラメーターを単一のプレイヘッドで統合制御。全6モジュールのスクリーンショットで全貌を公開。

// Key Features

展開のカーブを描くだけ。トランジション構築の完成形。

01 / 31 CURVES
1 プレイヘッド × 31 カーブ
ピッチ、レベル、デチューン、ノイズ、フィルターカットオフ、FXパラメータ。あらゆる自動化要素が1つの進行軸（LIFT）に完全同期連動。
02 / ABSOLUTE PITCH
Start Key → End Key 絶対ピッチ
MIDIノートはトリガーに過ぎません。どの鍵盤を押しても、設定した Start Key から End Key の目的音階へ寸分違わず正確に上昇。
03 / 70 SCALES
70スケール対応 Scale Quantize
ピッチスイープを任意キーのスケール音へスナップ。滑らかな滑空ライザーから、階段状にステップ上昇する音楽的なライザーへ即座に変貌。
04 / WAV CAPTURE & ROUTING
WAVドラッグ ＆ ソース別ルーティング
生成されたライザーをそのままDAWへWAVドラッグ＆ドロップ。4フィルター＆5FXは各ソース（OSC 1〜3, Noise）ごとに通過/バイパスを個別指定可能。

LIFT-X の全6モジュールと詳細仕様

01. メインパネル ＆ 31カーブ統合コントロール
単一のプレイヘッド（LIFT）によって制御されるメイン合成エンジン。3オシレーターのWavetable設定、ノイズジェネレーター、マスターリバース、WAVドラッグ生成が一体化。
02. 多点ベジェ・エンベロープ・エディター
各カーブ最大128ポイント。ベジェテンションハンドルで自由な曲線を自由自在にカーブ描写。28種類のプリセット（Exp, Log, Steps, Saw, Pulse等）を内蔵。
03. 4 ZDF/TPT フィルターマトリクス
Cytomicスタイルの台形統合TPT SVF（LP/HP/BP/Notch）。OSC 1〜3およびNoiseに対し、フィルターごとに通過・バイパスを独立マトリクス制御。
04. ソース別ルーティング付き 5スロット FXラック
Saturation (10 ADAA algo), Chorus, Delay, Reverb, Ducking。効果ごとにサブベースだけリバーブから除外するなどの柔軟なソースルーティングを実現。
05. 70種類のスケールクオンタイズ ＆ プリセットブラウザ
モード、日本古風（平調子・岩戸等）、ワールド、コードトーンなど70スケールを完備。11カテゴリのファクトリープリセットブラウザを内蔵。
06. システムコンフィグ ＆ エンジン設定
ライザー再生時間（1/32 Bar 〜 16 Bars）やマニュアルLIFTダイヤルの応答性、バッファキャプチャ品質の設定を直感的にカスタマイズ。
