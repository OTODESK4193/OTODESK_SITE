LIFT-X

ライザーはエンベロープではない——41個のカーブが同時に動く音楽的展開である。

LIFT-X は、トランジション表現の常識を覆すライザー特化型 VST3 シンセサイザー。オシレーター・フィルター・FXの全自動化パラメーターに41個の独立多点カーブを完備し、単一の進行軸（LIFT）で統率。画期的な REPEAT ×1–32、70スケールクオンタイズ、Vowel / Comb フィルター、Beat Stutter、そして DAW 直結の WAV ドラッグ機能を搭載。

// Key Features

展開のカーブを描くだけ。トランジション構築の完全回答。

01 / 41 MULTI-POINT CURVES
1 プレイヘッド × 41 カーブ
ピッチ、レベル、デチューン、ステレオ幅、PAN、ノイズ、4×フィルターCutoff/Res、14×FXパラメータ全41個が単一の軸に完全同期。最大128ポイント、ベジェ曲線で自在にカーブを描写。
02 / REPEAT ×1–32
カーブ単位のリピート（LFO化）
各カーブに独立して ×1〜32 のリピート数を設定可能。1回の描画で16分音符ゲートやテンポ同期のワブル（Wobble）エフェクトをモジュール追加なしで即座に構築。
03 / ABSOLUTE PITCH & REVERSE
絶対ピッチ ＆ 1ボタン反転
Start Key → End Key（オシレーターごと）の指定範囲へ正確に上昇。どの鍵盤を押しても狙った音階へ着地。1ボタンで41全カーブを逆再生する REVERSE（ライザー ↔ ダウンナー）を搭載。
04 / 70 SCALE QUANTIZE
70スケール対応 Scale Quantize
ピッチスイープを任意キーのスケール音へ自動スナップ。滑らかな滑空ライザーから、階梯状（メロディック）にステップ上昇する音楽的なライザーへ即座に変貌。
05 / VOWEL & COMB FILTERS
Vowel ＆ Comb フィルター搭載
人声フォルマントを再現する VOWEL（"aa-eh-ee" と喋るライザー）や、ノイズに音程を与えてスケール演奏させるフィードバック・レゾネーター COMB を含む 4 フィルター × 6 タイプ。
06 / BEAT STUTTER & WAV DRAG
Beat Stutter ＆ WAV ドラッグ
テンポ同期ビートリピート Beat Stutter 搭載の 5 スロット FX ラック。生成音は -90 dBFS サイレンス検出で完全録音し、DAW タイムラインへ 32-bit float WAV を直接ドラッグ＆ドロップ！

LIFT-X v1.0.0 の全6モジュールと詳細仕様

01. メインパネル ＆ 41カーブ統合コントロール
単一のプレイヘッド（LIFT）によって制御されるメイン合成エンジン。3オシレーター（Wavetable対応）、ノイズジェネレーター、音名表示 PITCH RAIL、マスターリバース、WAVドラッグ生成部が一体化。
02. 41多点ベジェ・エンベロープ・エディター
各カーブ最大128ポイント。ベジェテンションハンドルで曲線を自由描写。47種類の形状プリセット（Basic, Curved, Shape, Steps, Saw/Gate, Pulse, Motion, Random）および REPEAT ×1–32、SNAP グリッドを完備。
03. 4 ZDF/TPT フィルターマトリクス (Vowel / Comb)
Cytomicスタイルの台形統合TPT SVF（LP/HP/BP/Notch）に加え、人声フォルマント VOWEL、音階共振器 COMB を搭載。OSC 1〜3およびNoiseに対し、フィルターごとに通過・バイパスを独立マトリクス制御。
04. ソース別ルーティング付き 5スロット FXラック
Saturation (10 ADAA algo), Chorus, Delay, Reverb (Shimmer), Ducking, Beat Stutter。効果ごとにサブベースだけリバーブから除外するなどの柔軟なソースルーティングを実現。14個のFXパラメータがカーブ変調対応。
05. 134 ファクトリープリセット ＆ ブラウザ
11カテゴリ（EDM, Trance, Bass, Techno, Cinematic, Downer, Scale Riser, Dubstep, DnB, Hardstyle, Ambient）にわたる134プリセットを内蔵。音楽的ランダマイズ RANDOM ＆ 音色微調整 MUTATE 機能を搭載。
06. システムコンフィグ ＆ 10カラーテーマ
70スケール・クオンタイズ、Key Follow（Fixed / Follow Start / Follow End）、10種のカラーテーマ（Midnight, Sakura, Ocean, Forest, Sunset, Mono, Neon, Vaporwave, Amber, Arctic）、ブリックウォール・リミッター設定。
