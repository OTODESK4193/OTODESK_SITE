// Key Features

圧倒的な波形加工力 ＆ 統合エフェクト・プロセッシング。

01 / 3 MORPH SLOTS
3 Stage Morph × 18 モード
Bend, PWM, Sync, Mirror, Spec Gate, Harm Shift, Form Scale など18種類の処理モードを備えた3つのMorphスロット。同一テーブルから極限まで新たな倍音を紡ぎ出します。
02 / COLOR ENGINE
IR-Based Color Engine
インパルス応答（8タイプ）によって透明感あふれる結晶音や金属的共鳴を付加。演奏したコードから音色IRを自動学習生成する「LEARN」機能を搭載。
03 / OTT & SOOTHE
3-Band OTT ＆ Soothe 抑制
アグレッシブなアップワード/ダウンワード3バンド圧縮「OTT」と、不快なピーク共鳴を全自動抑える12バンド共鳴抑制「Soothe」を内部に完備。
04 / DEEP MODULATION
3 LFO + 2 MSEG + 3 ModENV
最大32ノードの多点ベジェMSEG×2、スムーズ/ディレイ付きLFO×3、スピード調整付きModENV×3。18スロットのMatrixで全パラメータを縦横無尽に変調。
05 / FORMULA GENERATOR
Real-time Math Wavetable Synth
三項演算子（? :）や比較・論理演算子、4モード（x/X/y/Y）対応の3 MODスロットを備えた数式合成エンジン。ライブミニスコープ表示、1クリック更新＆WAV保存に対応。
// Visual Walkthrough (全11画面)

Wavetable の全11モジュールと詳細仕様

01. メイン UI ＆ 3 Morph スロット
3次元波形表示を中心としたメイン操作パネル。1オシレーターの中に独立した3つの Morph モディファイア（18モード）を同軸配置し、変態的なウェーブテーブル変調を実現。
02. デュアル・マルチモード・フィルター (A/B)
9タイプ（LPF, HPF, BPF, Notch, Comb, Analog Ladder, Vowel, Comb+, Phaser）対応の独立2系統フィルター。直列/並列のルーティングを可視化ダイアグラムで操作。
03. Color IR エンジン ＆ Sparkle Arp
Crystal Saw, Shimmer PWM, Harmonic Bell など8種のインパルス音色。コード学習機能「LEARN」と、高音域を華やかに彩る Sparkle Arpeggiator を搭載。
04. 3-Band OTT ＆ Soothe 共鳴抑制
アグレッシブなUp/Down 3バンドコンプレッサー（OTT）と、12バンド全自動レゾネーションサプレッサー（Soothe）。主音とサブベースを個別に処理可能。
05. 3系統 モジュレーション・エンベロープ (ModENV)
スピード（Rate）コントロールとカーブ調整を備えた3系統のADSRエンベロープ。オシレーターのMorph、Filter、FXアンプへの動的追従を実現。
06. 3系統 LFO セクション
DAWテンポ同期 / フリーラン（0.02Hz〜20Hz）に対応する3基のLFO。スムーズコントロール、ディレイタイム、リリガーモードを完備。
07. 2系統 多点ベジェ MSEG (最大32ノード)
最大32ノードのグラフィカル多点エンベロープエディター。ベジェハンドルによる自由なカーブ形成、ワンショット/ループ再生モードに対応。
08. 18スロット モジュレーション・マトリクス
12ソース × 30デスティネーション。ノブ周りの白色アーク表示でリアルタイム変調を可視化。70スケール対応 Pitch Quantizer も完備。
09. 並び替え自在な 4スロット FXラック
Chorus, Delay, Reverb, Amp (キャビネットシミュレーション)。ヘッダーのドラッグで並び替え可能。主音（OSC）とサブベース（SUB）の独立エフェクトアサインに対応。
10. コンフィグ ＆ 10色の UI カラーテーマ
Midnight, Cyberpunk, Vaporwave, Sakura などの10種類のデザインテーマ。システムパラメータやプリセットブラウザを直感的に切り替え。
11. 数式ウェーブテーブルエディター (Formula Generator)
WT BROWSE パネル内に統合されたリアルタイム数学的ウェーブテーブル合成エンジン。三項演算子（? :）、比較演算子（<, >, <=, >=, ==, !=）、論理演算子（&&, ||）を含む高度な条件付き数式評価をサポート。

4ステートのリンクモード（x: 位相スロープ, X: 位相ウィンドウ×Posリンク, y: 静的オフセット, Y: フレーム y-グラデーション）を持つ3基の MOD スロット により、モジュレーション演算を数式へ動的に挿入可能。波形描画用のライブ・ミニスコープ、Stock Morph プリセット適用、1クリックによるウェーブテーブル更新および WAV 保存/エクスポートに対応。
