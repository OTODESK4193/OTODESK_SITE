8 FEATURE HIGHLIGHTS // 機能ハイライト

複雑なグラニュラー合成を「誰でも・即座に・音楽的に」扱えるように設計された8つのコア機能。

HIGHLIGHT 01 // PITCH 82 SCALES

絶対音感スケールクオンタイズ

Pitch Jitter（±24半音）やLFO変調をすべて加算した一番最後にKey＋Scaleへスナップ。どれほど過激にピッチを暴れさせても、絶対にスケールから外れないきらびやかな和音クラウドを生みます。

AUTO KEY DETECT POST-MOD SNAP
HIGHLIGHT 02 // ENGINE 3 CORES

3大エンジン＆独立フォルマント

王道のGranular、位相を整えて滑らかに引き伸ばすWSOLA、ピッチと声質（フォルマント±12st）を完全分離するTD-PSOLAをワンクリックで切り替え可能。

FORMANT SHIFT ±12 SEMITONES
HIGHLIGHT 03 // ATLAS O(log N) MAP

Concatenative 音色アトラス

サンプル内の「音の明るさ（Timbre）」「局所ピッチ」「ゼロクロス点」を瞬時に地図化。時間の順番ではなく「欲しい明るさの音色」をめがけてグレインを自動収集します。

ZERO-CROSS LOCK TIMBRE SCRUB
HIGHLIGHT 04 // RESONATOR PHYSICAL

ノイズを楽器化する物理共鳴

ノート周期で粒を撃つP-SYNC、弦の響きを生むTONEコムフィルタ、さらにマリンバ・ベル・金属板の響きを与える8モード物理モーダル共鳴器で環境音が極上の楽器に変わります。

P-SYNC + TONE 8-MODE MODAL
HIGHLIGHT 05 // RHYTHM 25 PATTERNS

ユークリッド×25種アルペジオ

25種類のアルペジオパターンに加え、ステップ・フィル・回転角を自在に操るBjorklundユークリッドリズム生成器を搭載。和音を押さえるだけで複雑なポリリズム・シーケンスが走り出します。

BJORKLUND E(k,n,r) SAFE RETRIGGER
HIGHLIGHT 06 // MODULATION 16 SLOTS

真のポリフォニック変調マトリクス

LFO×4（カオスアトラクタ含む）、ループ可能ENV×3、ベロシティ、MPEアフタータッチなど13ソース×77宛先。24ボイスそれぞれが独立してエンベロープやランダム変調を走らせます。

13 SRC → 77 DEST LIVE ARC DISPLAY

D&D並べ替え5スロットFXラック

ADAAサチュレーション（10種）、コーラス、ダッキング付きテープディレイ、粒状フリーズ、16chシマーリバーブ、母音FormantGateをドラッグで自由に順序変更（重複防止排他ロック付き）。

ADAA + SHIMMER FORMANT GATE

DSP ARCHITECTURE // SIGNAL TOPOLOGY

THE CHAOS OF GRANULAR, KEPT IN TUNE // 内部DSPアーキテクチャ

一般的なグラニュラーシンセは「スケール補正のあと」にランダムジッターやLFOを加えるため、動きをつけた瞬間に音痴になります。GRANULARは信号経路の根幹からこの順序を逆転させました。

KERNEL 01 // PITCH PIPELINE POST-MOD QUANTIZE

最終段スケールクオンタイズ回路

演奏ノート・Octave・Semi・Fine・Pitch Jitter（±2400ct）・Diatonic Swarm・全16スロットのピッチ変調をすべて合算した直後に、82種類のスケールクオンタイザーを通過。隣接オクターブ探索によりスケール端でも不自然なジャンプを起こさず、極限のカオス変調を音楽的ハーモニーへ変換します。

QUANTIZE STAGE: AFTER ALL MODS + JITTER
SCALE LIBRARY: 82 MODES + AUTO KEY
KERNEL 02 // ANTI-ALIASED READOUT MIP-MAP HERMITE

衝突回避スケジューラ＆ミップマップ補間

最大1,200グレインの同時発音でもCPUスパイクを防ぐ予算管理と、同一座標へのグレイン集中を防ぐGrainSwarmSchedulerを搭載。さらに31タップBlackman窓Sincピラミッド（2×〜16×ミップマップ）＋4点エルミート補間により、高域ピッチシフト時も折り返しノイズ（エイリアシング）を徹底排除します。

INTERPOLATION: 31-TAP SINC + 4-PT HERMITE
PER-GRAIN FILTER: ZAVALISHIN TPT SVF
KERNEL 03 // REAL-TIME SAFETY ZERO-CLICK ENGINE

非破壊ボイススティーリング＆多層安全設計

ポリフォニー上限に達してボイスが奪われる際も、古いグレインを即座に切断せず自身の窓関数で自然減衰させる非破壊スティーリングを採用。3msのリージョン端フェード、20msのPositionグライド、フィードバック系のDCブロッカー、1.5ms先読みブリックウォールリミッターにより突発的なクリックや発振を完全に防ぎます。

VOICE STEALING: NON-DESTRUCTIVE DECAY
OUTPUT PROTECTION: 1.5MS LOOK-AHEAD LIMITER
