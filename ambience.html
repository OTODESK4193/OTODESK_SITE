周期的なサイン波変調を廃止し、Smoothed-Random変調とUnitary帰還行列回転を新採用。深いMOD AMTでも音程が揺れず、残響だけが有機的に息づきます。

DSP ARCHITECTURE // SIGNAL TOPOLOGY

RESEARCH-GRADE REVERB ARCHITECTURE // 内部DSPアーキテクチャ

Schroeder/Moorer/Jotの古典的構造にとどまらず、学術文献に基づくFWHTユニタリ帰還行列、Välimäki-Liski 10バンドGEQ吸収、そしてv3.0.0のトゥルーステレオFDN×SDNハイブリッドを統合しました。

KERNEL 01 // TRUE STEREO FDN FWHT + UNITARY ROT

16ch トゥルーステレオ FDN ＆ ユニタリ変調

対数配置された互いに素な素数ディレイラインとFWHT帰還行列に、v3.0.0では独立L/Rネットワークと緩やかに変化するUnitary行列回転を実装。ピッチを一切揺らさずに空間の密度と立体感を最大化します。

LATE NETWORK: INDEPENDENT L/R TRUE STEREO
MODULATION: SMOOTHED-RANDOM + UNITARY
KERNEL 02 // STAGE 2 GEQ VÄLIMÄKI-LISKI WLS

10バンド Biquad GEQ 吸収＆64bit精度

各FDNチャンネルに10バンドBiquad GEQを直列接続し、重み付き最小二乗法（WLS）で目標RT60カーブへ高精度追従。64-bit倍精度演算とPing-Pongクロスフェードにより、最長200秒のテールでも量子化ノイズやツマミ操作時のクリックを排除します。

ABSORPTION: 16CH × 10-BAND WLS LDLT
FILTER PRECISION: 64-BIT DOUBLE TDF-II
KERNEL 03 // REAL-TIME SAFETY ZERO ALLOCATION

実戦堅牢設計＆1,200件自動音響検証

オーディオスレッド上のヒープ確保ゼロ、Dirty-FlagによるWLS演算抑制、Hermite分数ディレイ補間、Ableton Liveの非同期サンプルレート変更保護を実装。1,200パターンの自動音響検証を通過したスタジオ標準の安定性です。
