PicoSampler

クリエイティブな簡易サンプラー

8SLOTに配置した音をランダムに再生したり、スケールクオンタイズされたアルペジエイターを使い、アナタの想像力を解放します。49アンカーの Signalsmith タイムストレッチ、10万倍ズーム、16スロットModMatrix、5スロットFXラックを凝縮。2026.7.30 正式公開！

// Key Features

直感的な操作性と、妥協なき音質設計。

01 / SLOTS & POLYPHONY
8スロット × 32ボイス
Single / Layer / Random 再生モードを搭載。8つのスロットに配置したサンプルを柔軟にレイヤーおよびランダム発音させることが可能です。
02 / TIME-STRETCH
Signalsmith Stretch 49アンカー
-24〜+24半音の広大な範囲をカバーする49個のアンカーバッファを搭載。音程を変えずにピッチ・スピードを完璧にコントロール。
03 / ARPEGGIATOR & QUANTIZE
13パターンArp ＆ 16スケール
スケールクオンタイズ（16種類）と連動する13パターンのアルペジエイター。どんなサンプルも楽曲のキーと調和させます。
04 / MOD MATRIX & FX
16スロット Mod ＆ 5スロット FX
LFOやEnvelopeを縦横無尽にルーティング。並び替え自在な5スロットエフェクトラック（サチュレーション、コーラス、ディレイ、フリーズ、リバーブ）を内蔵。
// Visual Walkthrough

PicoSampler の主要機能とインターフェース

メインインターフェース ＆ 8スロット サンプラー
8つのスロットに自由に音声を割り当て、Single / Layer / Random のマルチプレイバックを集中コントロール。10万倍ズームとゼロクロススナップにより、超高精度な波形編集を実現。
アルペジエイター ＆ フィルターセクション
Up / Down / Random などの13パターンアルペジエイターと、16種類のスケールクオンタイズ、TPT SVFフィルターモデルを組み合わせ、どんな素材も音楽的フレーズへと昇華。
16スロット モジュレーション・マトリクス
LFOやエンベロープなどのソースから、Filter Cutoff, Pitch, Grain Size, FX Wet などの目的地へ自由に割り当て。バイポーラ/ユニポーラの切り替えとリアルタイム可視化に対応。
自由な順序で組める 5スロット FXラック
10アルゴリズムのサチュレーション、アンサンブルコーラス、テープディレイ、フリーズ、シマーリバーブ。ドラッグ＆ドロップでエフェクト順序を即座に変更可能。
コンフィグ ＆ システム設定
各種エンジンプロファイルの設定やシステム設定をスムーズに調整可能。直感的なダークテーマUIで快適なアサインワークフローを提供。
